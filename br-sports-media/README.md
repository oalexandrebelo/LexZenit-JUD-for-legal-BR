# Desportivo, audiovisual, cultura e apostas

Desportivo, audiovisual, cultura e apostas: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-sports-media@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

Ministério do Esporte; ANCINE; SPA/MF; entidades competentes

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-sports-media:sports-contract` — Relações desportivas e integridade.

- `/br-sports-media:audiovisual-culture` — Audiovisual, cultura e cadeia de direitos.

- `/br-sports-media:betting-compliance` — Conformidade de apostas.
