# Saúde, vigilância sanitária e saúde suplementar

Saúde, vigilância sanitária e saúde suplementar: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-health@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

ANVISA; ANS; SUS; conselhos profissionais

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-health:sanitary-product` — Produto regulado e vigilância sanitária.

- `/br-health:health-plan` — Cobertura e contratos de planos.

- `/br-health:clinical-data-research` — Pesquisa clínica e dados de saúde.
