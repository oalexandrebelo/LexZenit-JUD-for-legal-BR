# Fundação jurídica, fontes e evidências

Fundação jurídica, fontes e evidências: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-legal-core@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

STF; STJ; CNJ; tribunal e órgão competentes

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.
