# Minerário, títulos, barragens e CFEM

Minerário, títulos, barragens e CFEM: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-mining@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

ANM; órgãos ambientais; entes arrecadadores

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-mining:mining-title` — Pesquisa, lavra e cadeia de títulos.

- `/br-mining:mining-safety` — Operação, barragens e descomissionamento.

- `/br-mining:cfem-mining-contract` — CFEM e contratos minerários.
