# Militar, disciplina e processo penal militar

Militar, disciplina e processo penal militar: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-military@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

STM; Justiças militares; autoridades disciplinares

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-military:military-jurisdiction` — Competência militar.

- `/br-military:military-defense` — Defesa penal militar.

- `/br-military:military-discipline` — Disciplina e direitos funcionais.
