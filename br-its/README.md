# ITS, fiscalização eletrônica e cidades inteligentes

ITS, fiscalização eletrônica e cidades inteligentes: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-its@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

CONTRAN; SENATRAN; INMETRO; IPEMs; DETRANs; órgãos executivos de trânsito

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.
