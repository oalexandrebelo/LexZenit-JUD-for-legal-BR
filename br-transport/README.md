# Transportes terrestres, aquaviários e aviação

Transportes terrestres, aquaviários e aviação: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-transport@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

ANTT; ANTAQ; ANAC; autoridades portuárias; Marinha

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-transport:land-transport` — Rodoviário, ferroviário e concessões.

- `/br-transport:maritime-ports` — Marítimo, portuário e cabotagem.

- `/br-transport:aviation-passengers` — Aviação, RBACs e direitos dos passageiros.
