# Engenharia Jurídica BR

Engenharia jurídica brasileira: citações rastreáveis, estrutura LexML, privacidade local, avaliação de triagem e arquitetura interativa com fronteiras verificáveis.

- `/br-legal-engineering:citations-provenance` — Citações: extrair, resolver, autenticar
- `/br-legal-engineering:lexml-structure` — LexML: estrutura, exceções e alterações
- `/br-legal-engineering:privacy-local` — Privacidade: pseudonimização local por caso
- `/br-legal-engineering:ecli-identity` — ECLI: identidade sem inferir força jurídica
- `/br-legal-engineering:triage-evaluation` — Triagem: avaliar com abstenção e sem vazamento
- `/br-legal-engineering:source-lineage` — Referências, licenças e capacidade demonstrada
- `/br-legal-engineering:architecture-explorer` — Arquitetura navegável: contratos e confiança

Os comandos do plugin são workflows de revisão. O CLI Python implementa as funções determinísticas descritas, sem modelo NER treinado ou protocolo externo. Referências completas em `references/sources.json`.
