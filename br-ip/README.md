# Propriedade intelectual, software e conteúdo

Propriedade intelectual, software e conteúdo: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-ip@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

INPI; Judiciário; ANCINE

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-ip:ip-clearance` — Marcas, patentes e liberdade de operação.

- `/br-ip:ip-contracts` — Titularidade, cessão e licenciamento.

- `/br-ip:oss-content` — Open source e direitos de conteúdo.
