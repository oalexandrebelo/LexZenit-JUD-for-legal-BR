# Societário, registro empresarial e M&A

Societário, registro empresarial e M&A: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-corporate@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

DREI; Juntas Comerciais; CVM; CADE

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-corporate:corporate-authority` — Poderes, governança e deliberações.

- `/br-corporate:ma-diligence` — Diligência em M&A.

- `/br-corporate:shareholder-rights` — Acordos de sócios e desconsideração.
