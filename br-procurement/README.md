# Licitações, contratos públicos, concessões e estatais

Licitações, contratos públicos, concessões e estatais: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-procurement@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

TCU; TCEs; TCMs; CGU; PNCP; ente contratante

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.
