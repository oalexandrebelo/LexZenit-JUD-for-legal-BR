# Imobiliário, notarial e registral

Imobiliário, notarial e registral: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-real-estate@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

CNJ; corregedorias; registro de imóveis; município

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-real-estate:registry-diligence` — Diligência registral e cadeia dominial.

- `/br-real-estate:extrajudicial-title` — Usucapião e adjudicação extrajudiciais.

- `/br-real-estate:real-estate-contract` — Locação, incorporação e garantia fiduciária.
