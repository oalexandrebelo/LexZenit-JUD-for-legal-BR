# Contratos civis, empresariais e tecnologia

Contratos civis, empresariais e tecnologia: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-contracts@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

Judiciário; partes; órgãos setoriais

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-contracts:contract-review` — Revisão contratual por posição.

- `/br-contracts:amendment-renewal` — Aditivos, renovações e obrigações.

- `/br-contracts:contract-negotiation` — Negociação e riscos residuais.

- `/br-contracts:clause-checklist-br` — Revisão contratual.
