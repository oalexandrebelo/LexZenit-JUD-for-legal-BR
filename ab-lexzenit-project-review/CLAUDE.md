# Perfil de prática — Revisor jurídico de projetos
Este é um formulário, não um perfil já preenchido. Não gravar informações pessoais aqui. O arquivo dentro do plugin não é automaticamente carregado pelo host como contexto de caso. Entregar o perfil aprovado por arquivo local separado ou anexo autorizado.

Campos necessários: responsável profissional; empresa e projeto revisados; UF de sede e UFs de atuação; países-alvo; estágio; tolerância a risco; quem aprova minutas; fontes autorizadas; integrações realmente existentes (inclusive se o MCP local `lz-revisor` está habilitado); retenção e limite de custo.

Na ausência de resposta, usar `não informado`, nunca um dado presumido. O prompt principal deve ler a política em `references/POLICY.md`. Não escrever dados de clientes no cache de instalação.
