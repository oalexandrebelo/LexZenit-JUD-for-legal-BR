# Eleitoral e organização político-partidária

Eleitoral e organização político-partidária: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-electoral@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

TSE; TREs; Ministério Público Eleitoral

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-electoral:electoral-eligibility` — Registro e elegibilidade.

- `/br-electoral:electoral-communication` — Propaganda, IA e comunicação eleitoral.

- `/br-electoral:campaign-accounts` — Contas e financiamento eleitoral.
