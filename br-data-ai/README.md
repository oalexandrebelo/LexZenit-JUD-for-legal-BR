# Dados pessoais, IA, cibersegurança e produtos digitais

Dados pessoais, IA, cibersegurança e produtos digitais: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-data-ai@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

ANPD; CNJ; órgãos setoriais; Judiciário

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-data-ai:privacy-impact` — ROPA, RIPD e transferências.

- `/br-data-ai:data-rights-incident` — Direitos do titular e incidentes.

- `/br-data-ai:ai-governance` — Inventário e governança de IA.

- `/br-data-ai:digital-product` — Revisão de lançamento digital.

- `/br-data-ai:lgpd-compliance-validator` — Governança de dados pessoais.
