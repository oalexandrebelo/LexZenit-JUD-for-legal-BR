# Financeiro, pagamentos, capitais e ativos virtuais

Financeiro, pagamentos, capitais e ativos virtuais: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-finance@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

BCB; CVM; COAF; CMN

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-finance:financial-perimeter` — Perímetro regulatório financeiro.

- `/br-finance:capital-markets` — Fundos, ofertas e governança CVM.

- `/br-finance:aml-openfinance` — PLD/FTP e compartilhamento financeiro.
