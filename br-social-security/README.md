# Previdenciário, assistencial e complementar

Previdenciário, assistencial e complementar: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-social-security@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

INSS; CRPS; PREVIC; SUSEP; Judiciário

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-social-security:benefit-eligibility` — Elegibilidade e transições.

- `/br-social-security:special-retirement` — Atividade especial e prova técnica.

- `/br-social-security:benefit-review` — Revisões, recursos e assistência.
