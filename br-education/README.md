# Educação, pesquisa e prática jurídica supervisionada

Educação, pesquisa e prática jurídica supervisionada: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-education@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

MEC; conselhos de educação; OAB; instituições

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-education:education-regulation` — Regulação educacional.

- `/br-education:student-rights` — Contrato educacional e inclusão.

- `/br-education:legal-clinic` — Clínica jurídica e estudo supervisionado.
