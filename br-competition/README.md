# Concorrência, concentrações e concorrência desleal

Concorrência, concentrações e concorrência desleal: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-competition@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

CADE; Judiciário; Ministério Público

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-competition:merger-control` — Controle de concentrações.

- `/br-competition:cartel-screen` — Triagem de indícios de cartel.

- `/br-competition:competition-agreements` — Contratos e remédios concorrenciais.
