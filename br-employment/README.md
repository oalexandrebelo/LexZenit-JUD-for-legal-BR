# Trabalho, relações coletivas e saúde ocupacional

Trabalho, relações coletivas e saúde ocupacional: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-employment@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

MTE; MPT; TST; TRTs; sindicatos

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-employment:worker-classification` — Vínculo e terceirização.

- `/br-employment:pay-collective` — Jornada, remuneração e norma coletiva.

- `/br-employment:occupational-safety` — NRs, riscos e saúde ocupacional.

- `/br-employment:labor-risk-assessor-br` — Riscos trabalhistas.
