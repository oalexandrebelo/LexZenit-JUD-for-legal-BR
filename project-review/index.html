LexZenit · Project Review

O que o seu projeto precisa cumprir, do Brasil ao mundo.

O revisor lê o repositório de um projeto de IA, SaaS ou startup, pergunta o que o código não diz e aponta, norma por norma, o que falta no Brasil, no país que mais pesa para o seu mercado e no mundo.

Primeira parada: como funciona Explorar o catálogo

Um revisor, três níveis

Cada norma do catálogo tem nível, jurisdição, vigência e fonte. O revisor só aplica uma jurisdição quando ela alcança o projeto; o resto fica como prontidão, sem virar cobrança.

Como funciona

Quatro passos, sempre na mesma ordem, sem rede e sem executar o código do projeto.

  1. Lê o código

    Dependências, caminhos e cada linha procuram sinais: dados pessoais, CPF, IA generativa, pagamento, analytics, upload. O relatório guarda arquivo:linha, nunca o texto lido.

  2. Pergunta o resto

    UF de sede e de atuação, países-alvo, mercado principal, sócios, captação, menores e venda ao governo. O que ficar sem resposta continua desconhecido, sem palpite.

  3. Cruza com o catálogo

    Gatilhos em lógica de três valores escolhem as normas; a regra do N2 escolhe o país. Projeto de lei vai ao radar; sandbox e compras de inovação, às oportunidades.

  4. Entrega relatório e minutas

    Relatório N1, N2 e N3 com estado, severidade, fonte e evidência, mais as minutas brasileiras que fecham cada lacuna.

Estados do relatório

Cada obrigação recebe um destes estados. O motor nunca declara uma obrigação cumprida: achar o documento não prova que ele cumpre a norma.

Não conformidade evidenciada

Norma vigente, fonte oficial conferida, artigo identificado, jurisdição aplicável, gatilho forte e nenhuma evidência no escopo.

Inconclusivo

Fonte secundária, prontidão, vedação, alerta de competência, documento a revisar ou resposta pendente.

Não aplicável

Gatilho ausente ou UF e país fora do alcance, sempre com o motivo escrito.

Radar regulatório

Projeto de lei e tratado fora de vigor, como o PL 2.338/2023. Não gera obrigação hoje.

Documento fora do repositório

Política publicada no site, contrato assinado ou registro em cartório não aparecem no código. Declare cada um em respostas.evidencias para o revisor considerar.

Escolha do N2

A mesma regra do motor, aplicada em ordem: país fixado, mercado principal, EUA entre os alvos, primeiro país estrangeiro, indício de público na UE ou no Reino Unido e, por fim, EUA. Mude os campos e veja a decisão.

Instalar

Tudo sai do repositório público. O plugin é somente leitura; o motor e o servidor MCP rodam na sua máquina e você decide quando ligar.

Plugin ab-lexzenit-project-review

/plugin marketplace add oalexandrebelo/LexZenit-JUD-for-legal-BR
/plugin install ab-lexzenit-project-review@legal-br
/ab-lexzenit-project-review:revisar-projeto

Seis workflows: revisar projeto, mapa por UF, escolher N2, classificar risco de IA, kit de documentos e atualizar o catálogo.

Motor local e MCP · Python 3.11+

Sem dependências externas

git clone https://github.com/oalexandrebelo/LexZenit-JUD-for-legal-BR.git
cd LexZenit-JUD-for-legal-BR/runtime
python -m lz_revisor revisar ../../meu-projeto \
  --respostas respostas.json --saida revisao/ \
  --sarif revisao.sarif --falhar-em alta
claude mcp add lz-revisor -e PYTHONPATH="$PWD" -- \
  python3 -m lz_revisor mcp --raiz ../../meu-projeto

A saída nunca sobrescreve arquivo existente. --sarif e --falhar-em levam o revisor para o CI; --data revisa na data dos fatos. O MCP lê só a pasta de --raiz, não escreve e não acessa a rede.

Limites

Escritos antes das promessas, valem para todo relatório.

Minuta para revisão profissional, nunca parecer

  • 106 das 210 normas foram conferidas em fonte oficial; as demais estão como fonte secundária ou não localizada e nunca geram não conformidade.
  • Normas municipais e setoriais ainda não foram mapeadas. Acre e Espírito Santo não têm norma estadual localizada; ausência no catálogo não prova ausência de lei.
  • Vedações, como as práticas proibidas do AI Act, não se provam por documento e ficam inconclusivas até alguém confirmar.
  • Leis mudam. O catálogo tem data de corte em 16/10/2026; confira a vigência na data dos fatos.
