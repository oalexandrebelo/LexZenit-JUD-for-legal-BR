# Recuperação judicial, extrajudicial e falência

Recuperação judicial, extrajudicial e falência: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-insolvency@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

Juízo recuperacional; administrador judicial; credores

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-insolvency:credit-classification` — Classificação e sujeição de créditos.

- `/br-insolvency:restructuring-plan` — Plano e assembleia de credores.

- `/br-insolvency:dip-distressed` — DIP financing e alienação de ativos.
