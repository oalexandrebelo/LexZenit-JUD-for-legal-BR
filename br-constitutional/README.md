# Constitucional, direitos humanos e tutela coletiva

Constitucional, direitos humanos e tutela coletiva: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-constitutional@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

STF; Judiciário; Ministério Público; Defensoria

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-constitutional:constitutional-review` — Controle constitucional e precedentes.

- `/br-constitutional:fundamental-rights` — Direitos fundamentais e remédios.

- `/br-constitutional:collective-rights` — Tutela coletiva e comunidades.
