# Seguros, resseguros e previdência complementar

Seguros, resseguros e previdência complementar: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-insurance@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

SUSEP; CNSP; PREVIC

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-insurance:insurance-policy` — Apólice, exclusões e dever de informação.

- `/br-insurance:claims-handling` — Regulação e negativa de sinistro.

- `/br-insurance:complementary-pension` — Previdência complementar.
