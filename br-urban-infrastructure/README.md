# Urbanístico, habitação, saneamento e recursos hídricos

Urbanístico, habitação, saneamento e recursos hídricos: análise brasileira com fontes localizadas, controle temporal e revisão profissional obrigatória.

## Uso

Instalação local: `/plugin install br-urban-infrastructure@legal-br`.

As referências deste pacote são autossuficientes. Nenhum conector externo é instalado por ele.

## Órgãos e fontes

Municípios; ANA; agências locais; órgãos ambientais

Consultar `references/sources.json`: referências catalogadas não equivalem a vigência certificada nem textos ingeridos.

## Skills

- `/br-urban-infrastructure:urban-land` — Uso do solo e regularização.

- `/br-urban-infrastructure:water-sanitation` — Saneamento e água.

- `/br-urban-infrastructure:infrastructure-land` — Desapropriação e servidão.
